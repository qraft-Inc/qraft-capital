# Brand artwork

Approved Qraft Capital Primary logo (from Qraft_Capital_Logo_Suite):

| File | Use |
| --- | --- |
| `qraft-capital-primary-full-colour.svg` / `.png` | Light backgrounds (site header, social image) |
| `qraft-capital-primary-white.svg` / `.png` | Dark backgrounds (site footer) |
| `qraft-capital-primary-black.svg` / `.png` | Single-colour / monochrome uses |

The site renders the SVGs through `QraftLogo` in `src/components/brand/Wordmark.tsx`.
Favicons in `src/app/` (`icon.svg`, `favicon.ico`, `apple-icon.png`) come from the suite's Social_and_Favicon folder.

SystemMasters and CapitalMasters still use typographic wordmarks (`HouseWordmark`) until their artwork is supplied.
